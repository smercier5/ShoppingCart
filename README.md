
# Shopping Cart Prototype

This project is a prototype of a shopping cart web application designed to simulate the basic functionality of an e-commerce checkout experience. The goal of the project was to demonstrate front-end development skills and UI/UX design integration using modern web tools.

## Project Overview
The application allows users to browse items, add products to a shopping cart, and view cart updates dynamically. The interface was designed in Figma and then implemented in code.

## Features
- Add items to a shopping cart
- Update cart quantities
- Remove items from the cart
- Dynamic cart total updates
- Responsive UI layout

## Technologies Used
- JavaScript
- Node.js
- npm
- Vite (development server)
- HTML / CSS
- Figma (for UI design prototype)
