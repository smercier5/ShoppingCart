
# Shopping Cart Prototype

This project is a prototype of a shopping cart web application designed to simulate the basic functionality of an e-commerce checkout experience. The goal of the project was to demonstrate front-end development skills and UI/UX design integration using modern web tools.

## Project Overview
This project is a front-end prototype of an e-commerce shopping cart designed to simulate a typical online checkout experience. The goal of the project was to practice translating a UI design into a functional web interface while implementing interactive cart behavior.

The application demonstrates front-end development skills including dynamic user interface updates, component-based layout design, and development workflow using modern JavaScript tooling.

## Features
- Add products to a shopping cart
- Update item quantities in the cart
- Remove items from the cart
- Dynamic cart total calculation
- Responsive interface layout

## Technologies Used
- JavaScript – application logic and dynamic functionality
- HTML – page structure and content layout
- CSS – styling and responsive design
- Node.js – development runtime environment
- npm – dependency management and scripts
- Vite – local development server and build tooling
- Figma – UI/UX design prototype
